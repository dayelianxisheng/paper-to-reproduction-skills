# VLN 检查表

在 Standard 或 Deep 模式中使用。根据论文证据填写；未披露的信息标记为“未说明”，不要猜测。

| 项目 | 核心问题 |
| --- | --- |
| 任务类型 | 离散 VLN、VLN-CE，还是其他设定？仿真还是真机？ |
| 视觉输入 | 全景、RGB、RGB-D、视频或预提取特征？ |
| 语言输入 | 路径指令、目标描述，还是对话/交互语言？ |
| 历史表示 | RNN、历史 token、轨迹缓存、拓扑图或无显式历史？ |
| 空间表示 | 隐式状态、导航图、拓扑图、BEV 或语义地图？ |
| 动作输出 | 候选视点、离散动作、航点、速度控制或文本动作？ |
| 额外依赖 | 位姿、深度、导航图、GPS、地图、检测器或外部模型？ |
| 部署能力 | 能否迁移到连续环境或真机？主要阻碍是什么？ |

## 条件扩展

只在论文涉及对应主题时补充：

- **动态环境**：动态对象如何观测、预测和避让？训练与评测是否真的包含动态变化？
- **世界模型**：预测什么未来状态？预测结果是否参与规划？是否有独立证据证明预测有效？
- **在线适应**：测试时更新什么参数或记忆？监督信号来自哪里？是否存在遗忘、泄漏或计算开销？
- **长时程任务**：记忆如何更新和压缩？子任务如何切换？是否报告随路径长度增长的退化？

最后指出方法最依赖的一项输入或假设，因为它通常决定跨环境部署能力。
