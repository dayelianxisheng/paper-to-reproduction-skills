# Standard 与 Deep 输出模板

只保留能回答用户问题的栏目。不要为填满模板而读取无关章节。

## Standard

```text
# 论文概览
基本信息：
研究问题：
核心方法：
有效证据：
主要限制：

# 任务设定
任务与环境：
输入 / 输出：
关键假设与额外依赖：

# 模型数据流
输入 → 编码 → 历史/地图 → 融合 → 决策 → 动作

# 核心模块
模块 1：输入、输出、作用、必要性
模块 2：输入、输出、作用、必要性

# 训练与推理
数据、监督、主要损失、预训练和额外数据：
状态更新、动作选择、停止和规划依赖：

# 实验判断
数据集与指标：
关键结果：
公平性与成本：
核心消融是否充分：

# 研究结论
三个主要优点：
三个主要局限：
与用户方向的关系：
是否值得复现：
下一篇对比论文：
```

控制在约 1200–2000 个中文字；复杂论文可略增，但优先删除重复背景。

## Deep

先复用 Standard 中与问题相关的部分，再按用户明确要求追加一个或多个模块：

```text
# 核心公式
公式：
变量：
计算过程：
作用与直觉：
相较常规形式的变化：

# 论文—代码对应
论文模块：
代码文件/类/函数：
证据：
未确认之处：

# 复现资源
官方仓库与版本：
数据和预训练权重：
关键依赖与硬件：
最小验证路径：
阻塞项：

# 多论文对比
任务设定：
表示方式：
决策方式：
训练信号：
额外依赖：
性能与成本：

# 创新方案
现有缺口：
可检验假设：
最小方法改动：
对比基线：
消融与评价指标：
主要风险：
```

不要一次默认追加全部模块。代码映射必须以实际仓库文件为证据；复现可行性审计交由 `$evaluate-research-project` 完成。
